# Roadmap

The authoritative checklist lives in [`PLAN.md`](https://github.com/lvlrSajjad/hazardserve/blob/main/PLAN.md). Summary:

| Phase | Weeks | Exit artifact |
|---|---|---|
| 0 Formalize | 1–4 | design note, differentiation table |
| 1 Simulator + policy | 3–10 | installable package, all tables reproducible |
| 2 Trace-driven evaluation | 8–16 | results JSON, figures, confidence intervals |
| 3 Reference implementation | 14–22 | llm-d scorer plugin, vLLM KV-connector migration path |
| 4 Real hardware | 20–26 | fidelity plot, hardware ablations |
| 5 Paper, Pages, release | 24–30 | arXiv, DOI, artifact badges, launch post |

Pivot thresholds and risks are in `PLAN.md`.
